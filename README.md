# ENVI-met Learning Booklets

A collection of step-by-step learning materials for getting started with **ENVI-met**, from model preparation and database editing to simulation, thermal comfort analysis, and visualization.

These booklets were originally prepared for the **Integrated Design Project (IDP) course offered by A/S at ETH Zurich** in 2024, for which I lead the urban microclimate module. I am sharing them openly here in the hope that they can also be useful to students, architects, researchers, and others who are starting to work with ENVI-met.

## Learning sequence

The materials are intended to be followed roughly in the order below.

| Step | Material | Topic / tool |
|---|---|---|
| 1 | [ENVI-met Getting Started]((https://www.envi-met.info/public/files/docs/GettingStarted2021.pdf)) | Official ENVI-met introduction and workspace/project setup |
| 2 | `IDP-Booklet2-Database_Albero.pdf` | Database editing with Albero |
| 3 | `IDP-Booklet3-Modeling_wMonde.pdf` | Model preparation with Monde |
| 4 | `IDP-Booklet4-Modeling_wSpaces.pdf` | Model digitization and refinement with Spaces |
| 5 | `IDP-Booklet5-Simulation_wEnviguide.pdf` | Simulation setup with ENVI-guide |
| 6 | `IDP-Booklet6-Simulation_wEnvicore.pdf` | Running simulations with ENVI-core |
| 7 | `IDP-Booklet7-Comfort_Biomet.pdf` | Outdoor thermal comfort analysis with BIO-met |
| 8 | `IDP-Booklet7-Visualization_wLeonardo.pdf` | Visualization and result exploration with Leonardo |

### Booklet 1

The first part of the learning sequence uses the official **ENVI-met Getting Started** guide rather than a booklet developed for this course.

It introduces the basic ENVI-met workflow, including setting up a workspace and project. The guide is hosted by ENVI-met.

The remaining booklets build on this introduction and provide additional step-by-step guidance for the workflow used in the course.

## ENVI-met version

The course materials were prepared using **ENVI-met 5.5.1**. As ENVI-met continues to evolve, the interface and individual commands may differ slightly in newer versions. The overall workflow and concepts should nevertheless remain useful.

## Intended audience

These materials are primarily intended for students and researchers who are beginning to work with ENVI-met, particularly in the context of urban microclimate and outdoor thermal comfort simulation.

The booklets are deliberately practical and visual. They focus on guiding users through the software workflow rather than providing a comprehensive description of the underlying physical and numerical models.

For detailed information about ENVI-met's models, methods, and current functionality, please refer to the official ENVI-met documentation.
